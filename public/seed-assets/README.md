# Seed assets

Files referenced by seeded `Asset` records (`src/data/seed/assets.seed.ts`).
`image`/`gallery`/`annotatedMap` blocks render these for real now — they're
simple generated placeholder SVGs (not real concept art), just enough to
prove the render path works end to end and to give the demo project a
visual instead of a broken-image icon. Replace with real art any time by
overwriting the same filenames the seed data already references.
